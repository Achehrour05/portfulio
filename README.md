## 🚀 Fonctionnalités Clés

- **Hero & Présentation :** Section d'en-tête dynamique avec avatar, titre personnalisé et liens directs (LinkedIn, GitHub, Email).
- **Parcours Académique :** Historique de formation interactif (Baccalauréat, DEUST MIPC, Cycle d'Ingénieur FSTG) animé avec Framer Motion.
- **Compétences & Arsenal :** Vitrine visuelle des langages et frameworks maîtrisés (Python, Java, React, Spring Boot, FastAPI, Docker, PostgreSQL...).
- **Vitrine de Projets :** Cartes de présentation des projets phares (*Morocco Memory*, *Vanguard Combat*, *CalorieBurn Predictor*, *FPL Optimizer*).
- **Formulaire de Contact :** Interface réactive avec validation côté client et notifications interactives.
- **Accessibilité & SEO :** Balises OpenGraph enrichies, contrastes validés et navigation au clavier accessible.

---

## 🛠️ Stack Technique

- **Frontend :** React 19, JavaScript (ES6+), Framer Motion, React Icons
- **Design & Styles :** Bootstrap 5, CSS3 modulaire, responsive design fluide
- **DevOps & CI/CD :** GitHub Actions CI pour la compilation automatique

## 💻 Démarrage Local

```bash
# Cloner le projet
git clone https://github.com/Achehrour05/portfulio.git

# Se positionner dans le répertoire
cd portfulio/portfulio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm start
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## 🔧 Résolution des Problèmes Fréquents

- **Erreur de port 3000 déjà utilisé :** Configurez la variable `PORT=3001 npm start`
- **Cache npm corrompu :** Exécutez `npm cache clean --force && npm install`
